# Welcome to ILEX
A Python packages for analysing High Time Resolution FRB data, dynamic spectra and polarisation. 


## Documentation
Here is the documentation for [ILEX](https://tdial2000.github.io/ILEX/), which includes function definitions and worked examples.


## Installing ILEX
See the [ILEX wiki](https://github.com/tdial2000/ILEX/wiki/ILEX-Installation-Guide) for guides on installing and using ILEX.


## Latest updates to ILEX
1. The [SHRINE](https://github.com/marcinglowacki/SHRINE) code base-used for dispersion measure (DM) searching using structure maximisation [(Sutinjo et al. 2023)](https://iopscience.iop.org/article/10.3847/1538-4357/ace774)
has been incorporated into ILEX. To install SHRINE use the ``install_shrine.sh`` install script.

2. Many of the stand-alone scripts for plotting have been removed as ``FRB`` class methods have been improved.

3. Pulse searching algorithm has been improved. See (Dial et al. 2026, in prep).
